# Mobile Secure Mode

**낯선 Wi-Fi에서도, 내 PC로 들어오는 불필요한 접근을 줄이세요.**

Mobile Secure Mode는 Windows 11에서 공용 네트워크의 파일 공유·원격 접속·네트워크 검색 등 주요 접근 경로를 제한하고, 보호 설정이 적용됐는지 확인합니다. 사용 후에는 앱이 변경한 설정을 원래 값으로 복원합니다.

## 설치와 사용

1. [공식 다운로드](https://github.com/omo2kane-ops/Mobile_Secure_Releases/releases)에서 최신 `MobileSecureMode-…-Setup.exe`를 실행하고 Windows 관리자 권한 요청을 승인하세요. Windows 11 x64가 필요하며, .NET은 별도로 설치하지 않아도 됩니다.
2. 앱에서 **보안 모드 켜기**를 선택하고, **공용 네트워크 보호**의 적용 결과를 확인하세요. 자동 보호는 설정에서 직접 켜는 옵션입니다.
3. 사용을 마치면 **보안 모드 끄기**를 선택하세요. 개인 네트워크로 복원할 때는 연결 이름을 확인해야 합니다. 연결이 끊겨 복원이 보류되면 해당 네트워크에 다시 연결한 뒤 완료하세요.

앱 하단의 **업데이트**에서 새 버전을 확인하고 설치할 수 있습니다. 시작 시 자동 확인은 기본 꺼짐입니다. 제거할 때는 보안 모드를 끄고 보류된 복원까지 마친 뒤 **Windows 설정 → 앱 → 설치된 앱**에서 제거하세요. 설정·로그·복원 이력은 보존됩니다.

## 어느 정도 보호하나요?

- **주요 효과:** 같은 공용 네트워크의 다른 기기에서 이 PC의 공유·원격 접속 서비스로 접근할 수 있는 경로를 줄입니다. Windows 방화벽 설정을 적용하고 실제 적용 정책을 다시 확인합니다.
- **상태 표시:** `SECURE`는 앱이 담당하는 핵심 보호 설정을 확인했다는 뜻입니다. PC 전체의 안전이나 공격 차단 성공률을 뜻하지 않습니다. 경고가 보이면 공용 네트워크 보호의 활성 여부와 안내를 함께 확인하세요.
- **함께 사용:** Windows 업데이트와 백신을 유지하면 더 폭넓게 보호할 수 있습니다. 이 앱은 악성 파일·피싱을 탐지하는 백신이나 통신 전체를 암호화하는 VPN 기능을 제공하지 않습니다. 백신·디스크 암호화·VPN 등은 상태만 확인합니다.
- **DNS와 환경:** DNS 보호는 암호화 연결을 우선하지만 일반 DNS로 전환될 수 있습니다. 회사에서 관리하는 PC나 VPN에서는 정책에 따라 동작이 달라질 수 있으며, 공용 프로필의 VPN 경로도 차단 규칙의 영향을 받을 수 있습니다.

## 다운로드와 개인정보

공식 배포 경로를 이용하세요. 설치 파일은 아직 코드 서명되지 않아 Windows가 알 수 없는 게시자를 표시할 수 있습니다. 앱 업데이트는 HTTPS와 SHA-256으로 파일 무결성을 확인합니다. 해시는 게시자 서명을 대신하지 않습니다.

계정 가입이나 텔레메트리는 없습니다. 복원을 위해 네트워크 이름과 변경 전 설정을 PC에 저장합니다. DNS 보호는 선택한 DNS 서비스에 질의하며, 업데이트 확인·다운로드는 GitHub에 연결합니다. Wi-Fi 비밀번호와 BitLocker 복구 키는 수집하지 않습니다.

이번 버전의 변경 사항과 검증 범위는 함께 제공되는 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

공개 다운로드의 실행용 패키지는 Setup.exe 하나입니다. GitHub가 자동 표시하는 “Source code (zip/tar.gz)”은 공개 배포 저장소의 안내문·메타데이터이며 앱 소스나 실행용 ZIP이 아닙니다.

## ZIP을 별도로 받은 경우

일반 설치는 Setup.exe를 권장합니다. 관리용 ZIP은 압축을 푼 뒤 관리자 PowerShell에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-MobileSecureMode.ps1`을 실행해 Program Files에 설치하세요. 다운로드 폴더에서 앱을 계속 실행하지 마세요. ZIP 설치의 제거는 복원을 완료하고 앱을 종료한 뒤 관리자 PowerShell에서 함께 제공된 `Uninstall-MobileSecureMode.ps1`을 실행합니다.
